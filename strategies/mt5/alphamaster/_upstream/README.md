# AlphaMaster runtime subset

This directory contains the minimal AlphaMaster runtime required by the web
application: feature engineering, the formula registry/vocabulary, operators,
and StackVM. The source is derived from
`rosemarycox5334-debug/AlphaMaster` under AGPL-3.0. The full license is kept in
`LICENSE` next to this file.

Training scripts, the standalone web UI, execution adapters, test suites, and
sample data are intentionally excluded.
