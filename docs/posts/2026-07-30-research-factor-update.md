# QuantHub 研究工作流与因子验证更新

> 发布日期：2026-07-30
>
> 范围：综合评估、因子验证、回撤信号、美股数据、AI 设置与产品信息架构

这次更新不是简单增加几个技术指标，而是重新明确 QuantHub 从“研究证据”到“模拟执行”的完整路径。目标是让量化计算、AI 推理、策略实验和交易动作各自承担清晰职责，同时保留可复现、可审计的验证过程。

## 为什么要重新整理

此前新闻分析、价格行为、多模型判断和股票评估同时作为一级入口出现。它们的标的、周期和研究记录高度重合，容易让使用者重复运行同一组分析，也不利于判断一条结论究竟来自行情、AI 还是模型共识。

新版本把单标的研究统一为“综合评估”，内部按证据类型拆分：

```text
量化快照 + 新闻 AI + 价格结构 AI + 模型共识
                         ↓
                    综合研究记录
```

新闻、价格结构和模型共识仍保留独立兼容路由，便于调试和历史链接访问，但不再重复占用一级导航。

## 新增因子验证工作台

因子验证回答的不是“现在应不应该买”，而是“这个候选因子是否在未参与训练的数据上仍有预测力”。因此它与综合评估保持独立，并使用更严格的时间划分：

1. 前 70% 样本确定因子方向和组合权重。
2. 隔离与预测窗口相同的周期，降低标签泄漏风险。
3. 后 30% 样本只用于样本外评价和方法对比。
4. 信号延迟一个周期执行，并计入换手成本。

当前覆盖 14 个候选因子：

| 类型 | 因子 |
| --- | --- |
| 趋势 | EMA 趋势强度、20 周期动量、MACD 柱、ADX 方向 |
| 反转 | 均值回归、RSI 反转、布林反转 |
| 突破 | 20 周期通道突破 |
| 量价 | 量价确认、OBV 动量、Chaikin 资金流 |
| 风险 | 低波动、ATR 收缩、下行波动 |

每个因子展示样本外 Rank IC、Pearson IC、ICIR、滚动 IC 正值比例、命中率、近似 p 值以及 1/3/5/10/20 周期 IC 衰减。高相关因子会在训练段内去重，避免组合被同一种价格结构重复占权。

## 六种量化方法与风险指标

工作台同时比较买入持有、趋势跟随、动量轮动、均值回归、通道突破和多因子组合。收益只统计样本外区间，并提供：

- 年化收益、年化波动、Sharpe、Sortino 和 Calmar。
- 最大回撤、最长回撤周期、Ulcer Index。
- 95% VaR、95% CVaR、下行偏差。
- 胜率、利润因子、换手、交易次数、敞口和平均持有周期。

回撤雷达提供正常、观察、减仓、风险退出和修复五种状态。它是风险动作提示，不是绕过信号审核的自动下单指令。

## 当前指标快照

研究结果增加 RSI、MACD 柱、ADX、ATR/价格、布林 `%B`、相对成交量、实现波动率和下行波动率。基础指标保持确定性计算，不让大语言模型重复计算技术指标。

AI 更适合处理新闻语义、价格结构推理、候选因子生成、市场状态识别和组合增强。无论使用何种高级模型，因子状态仍必须通过样本外验证，AI 输出不能直接修改历史统计结果。

## AI 模型供应商设置

系统设置现在支持 DeepSeek、OpenAI 和自定义 OpenAI 兼容服务。可以在界面中配置 API 地址、模型、超时和重试次数，执行连接测试并读取可用模型列表。配置保存后热重载，密钥不会以明文返回前端。

这一设计让新闻 AI 与价格结构 AI 复用同一供应商配置，不再为每个分析模块维护第二套 Key 和模型参数。

## 美股历史数据改进

美股数据链路调整为腾讯实时数据优先、Yahoo Chart 历史数据回退、本地 Parquet 最终兜底。Yahoo 适配器当前支持日线和周线，会尝试两个 Chart 主机，清理缺失 OHLC 行并统一输出 QuantHub K 线结构。

这使 AAPL、NVDA 等美股标的能够直接进入综合评估和因子验证，不再依赖已有的本地历史文件。

## 功能边界调整

新的一级信息架构如下：

| 工作区 | 能力 |
| --- | --- |
| 研究 | 综合评估、因子验证、研究任务 |
| 策略 | 策略运行、策略实验、策略组合 |
| 执行 | 信号审核、模拟交易、账户账本、价格提醒 |
| 运营 | 标的与数据、作业调度、运行故障、成员权限、系统设置 |

完整的能力归属和新功能准入规则记录在 [功能边界](../FUNCTION_BOUNDARIES.md)。当一个新页面与现有能力拥有相同输入、相同核心计算和相同输出时，应扩展原能力，而不是再次创建一级入口。

## 兼容性与安全边界

- 旧的 `/news`、`/pa` 和 `/ensemble` 路由继续可用。
- 因子验证不会自动发布信号或创建订单。
- 实盘开关继续默认关闭，所有交易动作仍停留在人工审核和模拟交易链路。
- 历史统计、AI 解释和模型共识均不构成投资建议。

## 验证

本次更新通过 37 项后端测试与 24 项前端测试，并完成 TypeScript 类型检查和生产构建。测试覆盖产品流程、因子未来数据隔离和 Yahoo 数据适配。页面还在桌面与移动视口下完成了实际渲染检查，宽表只在自身容器内滚动，不会撑破整个页面。

QuantHub 下一阶段的 AI 增强应进入现有“因子验证”能力：使用滚动训练的数值模型学习非线性权重，并把市场状态作为组合约束。它不应成为另一套重复的 AI 因子页面。
