# QuantHub 更新：用 14 个因子、样本外验证和 AI 重做量化研究流程

> 这次更新的重点，不是继续堆叠技术指标，而是建立一套从“发现候选因子”到“验证是否有效”，再到“识别回撤风险”的完整研究流程。

最近我对 QuantHub 的研究模块做了一次较大的整理。

过去，量化快照、新闻分析、价格行为、多模型判断和股票评估分散在不同入口。功能看起来很多，但实际使用时容易遇到三个问题：同一个标的被重复分析、AI 结论和量化结果混在一起、看到高收益后却很难判断有没有过拟合。

因此，这次更新主要做了三件事：

1. 增加独立的因子验证工作台，用样本外数据筛选候选因子。
2. 加入更完整的回撤与尾部风险指标，输出明确的风险状态。
3. 重新划分量化计算和 AI 的职责，减少重复功能。

## 一、14 个候选因子，不再只看单一指标

新版本目前覆盖 14 个候选因子，分为趋势、反转、突破、量价和风险五类。

| 类型 | 因子 |
| --- | --- |
| 趋势 | EMA 趋势强度、20 周期动量、MACD 柱、ADX 方向 |
| 反转 | 均值回归、RSI 反转、布林反转 |
| 突破 | 20 周期通道突破 |
| 量价 | 量价确认、OBV 动量、Chaikin 资金流 |
| 风险 | 低波动、ATR 收缩、下行波动 |

这里需要强调一点：**系统展示的是候选因子，不是保证盈利的“神奇指标”**。

一个因子只有在未参与训练的数据上仍然保持预测力，才值得进入后续策略实验。为此，系统会展示：

- Rank IC 与 Pearson IC；
- ICIR、IC 正值比例和方向命中率；
- 近似 p 值；
- 1、3、5、10、20 周期的 IC 衰减；
- 因子之间的相关性和去重结果。

高度相关的因子不会被简单叠加。系统会在训练区间内做相关性去重，避免多个相似指标重复放大同一种行情特征。

## 二、用样本外验证降低过拟合

因子验证采用按时间顺序划分的数据，而不是随机打乱：

```text
前 70% 训练样本 -> 隔离区间 -> 后 30% 样本外验证
```

训练区间用于确定因子方向、筛选因子和计算组合权重；隔离区间用于降低预测标签泄漏；最后 30% 数据只负责验证，不参与调参。

回测信号还会延迟一个周期执行，并计入换手成本。这样虽然会让结果不那么“漂亮”，但更接近真实可执行条件。

## 三、同时比较 6 种量化方法

工作台目前会并行比较：

1. 买入持有；
2. 趋势跟随；
3. 动量策略；
4. 均值回归；
5. 通道突破；
6. 多因子组合。

所有方法使用相同的样本外区间和成本口径，避免因为测试区间不同而产生误导性的横向比较。

除了年化收益，系统还会计算 Sharpe、Sortino、Calmar、胜率、利润因子、换手率、交易次数、平均持有周期和实际敞口。收益只是结果的一部分，稳定性和风险同样重要。

## 四、回撤信号不只显示一个百分比

很多策略在上涨阶段表现接近，真正拉开差距的是回撤过程。因此这次更新增加了：

- 最大回撤与最长回撤周期；
- Ulcer Index；
- 95% VaR 与 95% CVaR；
- 下行偏差；
- 当前回撤、历史回撤位置和修复状态。

系统会把风险状态归纳为五个等级：

| 状态 | 含义 |
| --- | --- |
| 正常 | 当前波动与回撤处于策略可接受范围 |
| 观察 | 风险开始抬升，需要减少新增暴露 |
| 减仓 | 回撤或尾部风险明显恶化 |
| 风险退出 | 已触及预设风险边界 |
| 修复 | 从深度回撤中恢复，但尚未完全确认 |

这些状态是研究和仓位管理提示，不会绕过人工审核自动下单。

## 五、高级 AI 应该用在哪里？

这次也重新梳理了 AI 在量化系统中的位置。

RSI、MACD、ADX、ATR、波动率和回撤等指标应由确定性程序计算。让大语言模型重复计算这些数据，不仅成本更高，还会降低可复现性。

AI 更适合参与以下环节：

- 理解新闻、公告和事件语义；
- 分析价格结构、关键位置与失效条件；
- 根据研究目标生成候选因子或因子表达式；
- 识别市场状态，辅助决定不同因子的适用环境；
- 解释模型分歧和异常结果；
- 在严格约束下增强组合权重模型。

无论 AI 模型多强，它生成的因子都必须重新经过时间隔离、样本外 IC、交易成本和回撤验证。**AI 负责提出假设和解释证据，统计验证负责决定假设能否保留。**

系统设置现已支持 DeepSeek、OpenAI，以及自定义 OpenAI 兼容服务。API 地址、模型、超时和重试次数可以统一配置，新闻分析和价格结构分析共用同一套供应商设置。

## 六、重新整理产品功能，避免重复入口

更新后的主流程是：

```text
标的与数据
    ↓
综合评估 / 因子验证
    ↓
策略实验
    ↓
信号审核
    ↓
模拟交易与账户账本
```

“综合评估”负责回答当前标的发生了什么，“因子验证”负责回答某个因子是否具有样本外预测力。两者可以共享基础行情数据，但不会重复承担同一职责。

新闻 AI、价格结构 AI 和模型共识被收进综合评估流程，不再作为多个重复的一级研究入口。原有链接仍然保留兼容，不影响已有使用方式。

## 七、美股历史数据和工程可靠性

美股数据链路增加了 Yahoo Chart 历史行情回退，支持日线和周线数据。AAPL、NVDA 等美股标的现在可以直接进入综合评估和因子验证，不再要求本地预先存在历史文件。

本次更新已通过：

- 37 项后端测试；
- 24 项前端测试；
- TypeScript 类型检查；
- 前端生产构建；
- 代码格式与敏感信息扫描。

随后补充的 PA Agent 适配还增加了两层保护：一是结构、概率、终局、价格几何和正期望质量闸门；二是 `K1=最新已收盘 bar` 的引用范围检查。AI 如果引用了本次输入窗口之外的 K 线，系统会阻断结果并要求模型按字段修正，仍不通过就不会发布信号。账户账本同时加入 FIFO 闭合交易分析，用真实闭合记录统计胜率、利润因子、盈亏比、持仓时长和费用侵蚀。

## 如何开始使用

1. 在“标的与数据”中确认目标股票和数据源可用。
2. 进入“因子验证”，选择市场、周期、预测窗口和交易成本。
3. 先看样本外 IC、稳定性和衰减，再比较不同方法的收益与回撤。
4. 将通过验证的候选方案送入“策略实验”，不要直接根据单次结果交易。
