## 一、合规底线（这次很轻）

1. **极限词（广告法第九条）**：描述项目时避免"最 / 第一 / 唯一 / 顶级 / 最佳 / 国家级"。换成"可 / 支持 / 已集成"。
2. **AI 内容标识**：若视频含 AI 生成 / 合成的画面、配音、虚拟场景，片头或角标加"AI 合成演示"，并埋隐式水印（各平台也强制要求）。
3. **不越线 + 不露密**：不出现"跟着买 / 稳赚 / 年化 %"；不把模拟、回测当收益展示；录屏时不要暴露 API Key、Passphrase 等密钥。

> 你不推荐、不荐股、不放收益，所以"保本保收益 / 非法证券投资咨询 / 非法集资"等重雷基本碰不到。保留上面 3 条即可。
