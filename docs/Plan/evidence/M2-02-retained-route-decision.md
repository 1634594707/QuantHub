## 推荐裁决

### `/governance`

现状：已移出主导航，但仍是成员、角色、访问令牌签发和审计日志的唯一界面。源码字面引用分布在 `main.tsx`、导航测试和页面自身。

- [ ] **推荐：恢复为“设置 / 治理与审计”受控二级入口。** 保留必要管理能力，同时不增加新的一级分类。
- [ ] 物理下线页面、路由及仅由它使用的 API/类型/测试。

### `/strategy-lab`

现状：已移出主导航，但命令面板、系统设置和因子研究页面仍有运行时引用；它也是策略定义、版本、实验、回测和对比能力的现有界面。

- [ ] **推荐：并入“策略 / 策略运行”后删除独立路由。** 先迁移仍需保留的实验和回测能力，再清理旧页面与孤立 API。
- [ ] 恢复为“策略 / 策略实验”受控二级入口。
- [ ] 连同入站引用及不再使用的实验 API 一并物理下线。

### `/factor-research`

现状：已移出主导航；独立因子实验与首期 OKX 交易闭环不直接相关，但研究结果工具和策略实验仍引用部分因子研究 API。

- [ ] **推荐：删除独立页面和路由，只保留被主研究/策略流程真实调用的 API。** 对 API 做调用方扫描后删除孤立端点。
- [ ] 恢复为受控研究入口。
- [ ] 页面、路由、全部因子实验 API 和数据链整体下线。

### `/news`、`/pa`

现状：没有独立一级入口，导航展示为“标的研究”的新闻证据和价格结构；仍存在独立路由、页面以及从研究入口进入的链接。

- [ ] **推荐：并入 `/research/:symbol`，随后删除两个独立路由。** 保留新闻和价格结构能力，不保留重复页面边界。
- [ ] 保留为研究深链，不恢复独立导航入口。
- [ ] 连同页面和仅由它们使用的 API/组件整体下线。

### `/portfolio`

现状：当前是“策略 / 策略组合”的正式二级入口，不属于隐藏直链。

- [ ] **推荐：保留。** 本轮不纳入 M2-02 删除范围。
- [ ] 缩减策略组合能力并物理下线。

### `MarketBreadth`

现状：研究页面仍引用该模块；假数据扫描的精确豁免不等于其行情统计口径已获业务验收。

- [ ] **推荐：真实全市场口径未接通前删除模块。** 以后以可追溯数据源重新实现。
- [ ] 保留并接入真实全市场口径，补充 `source/observed_at/freshness/status` 契约和测试。
