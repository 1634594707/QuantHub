# QuantHub 架构改进路线图：多用户 · 流程 · 报告质量

> 制定日期：2026-08-25
> 定位决议（用户确认）：**走向多用户**；优先级主轴为**流程闭环**与**报告质量**。
> 基线：`docs/PRODUCT_USABILITY_AND_REPORT_REQUIREMENTS.md`（审计日 2026-08-22）。该文档已给出具体源码证据（文件、函数、表名）；本路线图沿用其结论，但**每项动工前必须先复核对应源码现状**——审计之后代码可能已变化，复核结果回填到各项的「现状核对」小节后才允许开工。

## 优先级结构

- **P0-A 存储与请求链路的用户归属**（多用户的前置工程，不完成则其余多用户功能不可信）
- **P0-B 报告单一事实源与后台生成**（用户指定的质量主轴）
- **P1-C 前端偏好收敛到账户级**
- **P1-D 前端请求层统一（去重 / 缓存 / 轮询协调）**
- **P1-E 结论解释结构统一**
- **P2-F Table API 扩展并退役三套 div 网格**（承接 2026-08-25 前端路线图 T6 裁决）

需求来源：审计文档 §4.1 已列明的缺口清单——`apps/api/domains/portfolio/router.py` 的 `get_portfolio()/add_holding()/update_holding()/delete_holding()` 无 `Request`；repository 层无 `owner_id` 参数；`store.py` 中 `holdings`、`portfolio_allocs`、`signals`、`ledger_trades`、`simulation_orders` 表无用户字段；simulation/ledger 路由未读身份；`search` 全局检索无过滤；`alerts/check` 遍历全部启用规则。

- [ ] A-1 现状核对：逐条验证上述位置在当前 HEAD 是否仍如审计所述（产出核对清单，变化的条目标注新现状）
- [ ] A-2 schema 迁移：五张表补用户归属字段 + Alembic 迁移脚本 + 存量数据回填策略
- [ ] A-3 链路贯通：路由从 `Request.state.principal` 取身份 → service → repository 全链路传参，禁止在 service 内自行"猜"身份
- [ ] A-4 搜索与提醒按主体隔离；跨用户访问统一 404 不泄露存在性，审计记录拒绝原因
- [ ] A-5 验收：双用户各自写入持仓/信号/订单/账本/提醒后，互相的读、写、删、导出、搜索均不可见对方数据（对齐审计文档 §4 验收）

## P0-B 报告单一事实源与后台化

需求来源：审计文档 §3。现状证据：`ResearchWorkspacePage.tsx` 用 `buildReadableReport(detailedRun)` 直接构建报告、导出走 `createReadableReportHtml`、`ResearchReportStream.tsx` 另行读取 `ResearchReport`；`apps/api/domains/workspace/report_service.py::generate_report()` 在请求内同步生成。

- [ ] B-1 现状核对：确认双源结构与同步生成仍为现状；确认前端是否仍未接 `/workspace/reports/{report_id}/stream` SSE
- [ ] B-2 事实源约定落地：`ResearchDecision`=结构化决策源，`ResearchReport`=解释与展示源，`ResearchRun` 不得绕过报告状态成为正式导出源
- [ ] B-3 创建接口立即返回报告记录，章节生成转后台任务；事件固定为 `report_started / section_started / delta / section_completed / report_completed / report_error / heartbeat`，每事件含 `task_id / research_run_id / report_id / sequence / event_version` 与服务端时间
- [ ] B-4 前端改用 SSE + `Last-Event-ID`/`after_sequence` 续传，去重、乱序保护、心跳超时、用户隔离
- [ ] B-5 停止语义：停止后无新章节事件；已完成章节保留，未开始标记取消
- [ ] B-6 单章重试产生新报告版本，只替换指定章节；旧版本继续可读
- [ ] B-7 门禁：仅 `report_completed` 且最终快照哈希校验通过的报告允许导出、复盘、关联提醒与进入执行链路
- [ ] B-8 验收：断线续传无重复；停止即止；单章重试不损其他章节；未完成报告的导出/执行接口返回明确阻断原因
