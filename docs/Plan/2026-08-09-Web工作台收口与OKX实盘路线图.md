## 1. 最终形态

- [x] 唯一前端入口为 `web/`，开发地址固定为 `http://127.0.0.1:5173`。
- [x] 唯一对前端公开的后端入口为 `apps/api`，前端只请求 `/api/*`。
- [x] `apps/okx_runner` 取消独立前端，只保留无 UI 的交易执行、风控、订单状态机和对账能力。
- [x] 浏览器不直连 OKX，也不持有 OKX API Key、Secret 或 Passphrase。
- [ ] 研究、策略、信号、订单、成交、持仓、资金和风险状态形成可追踪闭环。
- [x] 生产页面只显示真实接口返回的数据；自动种子、演示 reset/seed 链和 mock 降级已删除，数据不可用状态已完成多视口复核。
- [x] 默认运行模式为研究或只读模式；实盘必须经过模拟盘验收和人工启用。

### 目标运行结构

```text
Browser
  -> web/ (React + Vite, 唯一用户界面)
  -> apps/api (统一认证、业务 API、审计、交易代理)
       -> 行情/研究/策略服务
       -> apps/okx_runner (无 UI、独立进程、最小权限)
            -> OKX REST/WebSocket API
       -> SQLite/PostgreSQL
```
