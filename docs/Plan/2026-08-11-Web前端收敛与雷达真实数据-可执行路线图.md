## 0. 路线关系与暂停边界

本路线是当前 Web 产品与数据真实性的执行入口。以下两份旧路线自 2026-08-11 起搁置：

- [QuantHub Web 工作台收口与 OKX 实盘路线图](2026-08-09-Web工作台收口与OKX实盘路线图.md)
- [QuantHub Web 工作台与 OKX 实盘可执行工作安排](2026-08-09-Web工作台与OKX实盘-可执行工作安排.md)

搁置期间不得继续推进旧路线中的 M4 后续连续观察、M5 风控准入、M6 小额实盘和依赖这些阶段的关闭动作。已经完成的代码、测试和证据继续保留，不回退、不删除，也不把旧证据改写成当前结论。

[AI 因子发现与交易验证路线图](../../AI_FACTOR_DISCOVERY_ROADMAP.md) 继续执行。旧路线恢复必须同时满足以下条件：

1. 至少一个真实因子通过锁定确认。
2. 该因子在 OKX Demo 完成不少于 7 个真实自然日的连续前向观察。
3. 研究收益与模拟收益差异归因已经完成。
4. 成交、成本、容量、回撤、风险和对账门禁全部通过，因子进入 `trading_validated`。
5. 项目负责人明确下达恢复旧路线的指令。

在上述条件全部满足前，Web 只提供研究、真实数据查看、信号核验和模拟能力，不以界面可操作替代交易因子有效性证据。

## 1. 已核对的当前事实

### 1.1 雷达固定 30% 的完整数据链

前端 [RadarPage.tsx](../../web/src/pages/RadarPage.tsx) 没有在本地生成 `30%`。页面把 `/signals` 返回的 `confidence` 转换为百分数直接显示。固定值来自上游和选取逻辑：

1. `strategies/a_shares/realtime_analyzer/strategy.py` 在 LLM 不可用时仍发布信号，并写入 `confidence=0.3`。
2. `strategies/us_stocks/realtime_analyzer/strategy.py` 使用相同的 `confidence=0.3` 降级值。
3. `strategies/ai_analysis/pa_agent/strategy.py` 在 `trade_confidence` 与 `diagnosis_confidence` 均缺失时写入 `confidence=0.3`。
4. `/signals` 按 `ts_epoch DESC, id DESC` 返回数据；`RadarPage.tsx` 顺序遍历后持续覆盖同一 `symbol`，因此旧记录覆盖新记录。
5. 雷达使用 `symbol` 作为信号映射键，而标的池使用 `market + symbol`，两个身份口径不一致。
6. 雷达请求没有限定信号生命周期状态，`expired`、`rejected`、`converted` 记录均会进入前端选取集合。

2026-08-11 对 `apps/api/store.db` 进行只读查询得到：

| 项目 | 精确结果 |
| --- | ---: |
| `signals` 总记录数 | 107 |
| `confidence=0.3` | 61 |
| `realtime_analyzer` 总记录 | 60 |
| `realtime_analyzer` 中 `confidence=0.3` | 57 |
| `realtime_analyzer_us` 总记录 | 6 |
| `realtime_analyzer_us` 中 `confidence=0.3` | 4 |
| `confidence` 不同数值数 | 4 |
| 信号来源数 | 5 |

同一账本还存在 41 条明确的测试数据：`api_test` 21 条、`E2E-*` 的 `pa_agent` 记录 19 条、`playwright_mobile` 1 条。这些记录不得继续出现在生产工作台的雷达、信号审核、总览计数和全局检索中。

### 1.2 前端功能过载

- `web/src/navigation/workspaces.tsx` 的完整模式固定展示 6 个一级工作区和 18 个二级入口。
- `web/src/main.tsx` 注册 25 个生产路由入口。
- `useInterfaceMode.ts` 在没有本地存储值时直接返回 `advanced`。
- 界面模式只影响侧栏、移动导航和命令面板，没有控制业务页面内容。
- `OverviewPage.tsx` 默认展示 5 个模块，`hidden` 初始值为空；页面创建 11 个 `useApi` 数据订阅，行动队列包含 9 类事项。
- `FactorResearchPage.tsx` 同时提供“因子工厂、当前研究、横截面、研究治理、历史记录”5 个视图；因子工厂内部又展示 4 个阶段和多组工具。
- `Sidebar.tsx` 在策略工作区直接渲染全部已注册策略，没有收藏、最近使用或收起边界。
- `Topbar.tsx` 与 `StatusBar.tsx` 重复显示连接、信号和运行状态。
- `ConfigPage.tsx` 把界面模式放在运行状态、凭据和 OKX 通道之后，首次使用无法直接发现。

### 1.3 导航归属错误

`/demo-lab` 已注册为“交易 / 模拟实验室”，但 `ROUTE_PRESENTATIONS` 没有对应项。进入该页面后，`presentationForPath` 回退到“总览”，侧栏、顶栏和状态栏失去真实页面归属。`/strategy-lab` 与 `/governance` 存在相同问题。

现有导航测试只验证 `/demo-lab` 出现在交易入口数组中，没有验证 `workspaceForPath('/demo-lab')` 和 `presentationForPath('/demo-lab')`。因此当前 14 项导航测试通过不能证明直达路由归属正确。

### 1.4 功能边界漂移

`docs/FUNCTION_BOUNDARIES.md` 已定义因子验证、策略运行、策略实验和模拟交易的唯一职责，没有定义“模拟实验室”。当前 `/demo-lab` 同时提供因子与策略回测，却作为交易工作区固定入口；而具有版本、实验、可复现运行和对比职责的 `/strategy-lab` 已移出一级导航。

在完成输入、计算、结果和数据所有权审计前，不再新增“实验室、工厂、中心、工作台”类一级入口。

### 1.5 现有前端设计基线

当前前端已经具备可继续使用的设计基础，不进行整套替换：

- `web/src/styles/tokens.css` 已定义暗色与亮色双主题、4 层背景、3 层边框、4 层文本、涨跌与警告语义色、4px 间距基准、3px 至 8px 圆角和统一动效时长。
- 全站字体使用 `Bahnschrift / Segoe UI`，数字使用 `Cascadia Mono`，符合研究与交易工作台的扫描需求。
- `Button` 已有 30px、36px、42px 三档高度和主、次、幽灵、危险、文字动作变体。
- 全局已有清晰的 `focus-visible` 样式与 `prefers-reduced-motion` 处理。
- 图标继续使用项目现有的 `lucide-react`，不得在同一产品内再混入第二套图标家族。

当前设计债务集中在信息层级和密度，不在颜色或技术栈：

- 通用 `.card` 默认同时使用边框、背景和阴影，页面大量区块呈现为同等权重的卡片。
- `WorkspaceHeader` 在标题旁同时放置说明和多项指标；移动端指标使用横向滚动，首屏仍承担过多信息。
- 桌面 `.content` 使用统一 24px 内边距但没有按页面类型区分内容宽度，长表格、研究报告和表单采用同一布局策略。
- 30px 小按钮在移动端仍保持桌面尺寸，触控区域不足。
- 因子页存在大量英文大写眉题、阶段条、分段控制和卡片标题，多个层级使用相近的视觉强度。

本路线采用定向演进：保留路由、业务文案、双主题、语义色、键盘能力和现有组件 API；只调整层级、密度、布局、状态表达和交互反馈。

## 2. 不可违反的产品与数据规则

1. 数据不可用时必须显示不可用原因，不得使用 `0.3`、`0.5`、`0` 或其他数值冒充实际结果。
2. 只有真实计算产生且能回链到输入、时间、来源和版本的数值才能显示为把握度、评分、收益或风险指标。
3. 测试、截图和演示运行必须使用隔离数据库，不得写入 `apps/api/store.db`。
4. 过期、拒绝、已转换和测试信号不得作为雷达当前信号。
5. 雷达必须明确区分：真实报价可用但信号缺失、报价缺失、信号过期、接口失败。
6. 精简界面只改变展示和数据加载范围，不删除业务能力，不改变研究或交易结论。
7. 新增功能优先放入现有职责页，不新增平级入口。
8. 旧路线继续保持搁置，直到第 0 节的五项恢复条件全部满足。
9. 视觉设计服务于扫描、比较和决策，不使用营销页式大标题、装饰性渐变、玻璃卡片、发光效果或无业务含义动画。
10. 颜色只表达品牌强调、涨跌、成功、警告和错误；同一状态在所有页面使用同一语义色。
11. 桌面端保持专业密度，移动端减少同屏指标和操作数量，不把桌面布局等比压缩到 390px。

## 9. R5：前端视觉与交互设计调整

### R5-01 设计方向与约束

本项目按高频量化研究与交易工作台设计，目标语言是安静、克制、可信、可扫描。设计参数固定为：

| 参数 | 数值 | 约束 |

| `DESIGN_VARIANCE` | 3 | 布局稳定、位置可预测，不使用实验性构图 |
