## 一、现状结论

当前产品已经具备可信研究底座，但尚未形成普通投资者可以长期使用的完整股票分析体验。

- [x] 已有唯一的单标的入口：`/evaluate -> /research`。
- [x] 已有量化快照、个股新闻、价格结构 AI、模型共识和统一 `ResearchDecision`。
- [x] 已有研究证据归档、方向冲突失败关闭、历史记录与差异比较底座。
- [x] 已有 `FinancialStatement` 点时财务数据契约，可表达会计准则、公告时间、数据来源和修订版本。
- [x] 已有 `fundamental_snapshot`、`valuation_snapshot`、`factor_exposure` 证据槽位和覆盖状态展示。
- [x] 综合评估任务已采集并生成点时基本面与估值证据；A 股和美股全面评估均接入对应财务模块。
- [x] 财务数据已具备提供方适配、标准化、不可变持久化、修订并存和研究编排。
- [x] 已新增独立宏观事件域、央行决策、经济数据日历和基于标的关系的事件传导链。
- [x] “快速 / 均衡 / 全面”只控制计算范围，四种研究模式独立控制用户信息密度。
- [x] 已形成结构化“结论、原因、风险、条件、失效、复核动作”用户决策卡。

因此，本路线图不新建第二套股票分析产品，而是在现有综合评估中补齐真实数据、分析规则和分层呈现。

## 二、产品目标

主链路统一为：

```text
标的与用户目标
  -> 点时行情 / 财报 / 估值 / 公司事件 / 宏观事件
  -> 各模块独立分析
  -> 统一证据与冲突判断
  -> 场景化建议参考
  -> 观察条件、提醒和历史复盘
```

最终用户应能回答六个问题：

1. 这家公司现在发生了什么？
2. 财务质量和盈利趋势是否改善或恶化？
3. 当前价格相对自身历史和可比公司是否昂贵？
4. 个股新闻、公司公告和全球事件通过什么路径影响它？
5. K 线与基本面、估值、事件证据是否一致，哪里存在分歧？
6. 当前更适合继续观察、分批关注、持有复核、降低风险还是退出观察，触发条件是什么？

## 三、用户分层与统一体验

用户分层只改变默认信息密度、术语和交互，不改变底层数据、计算结果和风险门禁。

| 用户类型 | 核心任务 | 默认视图 | 保留能力 | 不默认展示 |
| --- | --- | --- | --- | --- |
| U1 快速判断用户 | 几分钟内理解结论、原因和风险 | 简明模式 | 结论卡、三条依据、三条风险、近期事件、观察动作 | IC、原始财务科目、模型参数 |
| U2 主动投资者 | 判断是否值得继续研究、持有或降低风险 | 投资研究模式 | 财报趋势、估值区间、K 线、事件时间线、场景条件、提醒 | 因子实验细节、工程诊断 |
| U3 专业研究用户 | 复核来源、口径、可比公司和模型分歧 | 专业验证模式 | 原始证据、财务修订、估值假设、模块意见、历史差异、导出 | 无；高级内容按需展开 |
| U4 量化研究用户 | 验证因子与策略并连接已有研究 | 量化实验模式 | 因子验证、股票池、策略实验、成本与归因 | 普通用户引导文案 |

### UX-00 用户模式契约

- [x] 定义 `UserResearchPreference`：默认模式、市场、持有状态、研究周期、风险偏好和术语级别。
- [x] 首次评估在同一入口提供简明、投资研究、专业验证和量化实验四种选择。
- [x] 用户可随时切换模式，同一研究记录不重新计算、不产生不同结论。
- [x] 深链接保存当前视图模式，但研究结果 ID 保持一致。
- [x] 模式切换不得隐藏证据不足、方向冲突、数据过期或风险警告。

**验收标准**

- [x] 四种模式读取同一 `research_run` 和同一 `ResearchDecision`。
- [x] 简明模式可以少展示，但不能改变方向、置信度、覆盖状态和建议条件。
- [x] 用户切换模式后，标的、周期、研究记录和历史选择保持不变。

## 四、核心数据契约

### DATA-00 点时性、来源与新鲜度

- [x] 所有财报、估值、新闻、公告和宏观事件保存 `source`、`source_url`、`published_at`、`available_at`、`fetched_at`、`revision` 和内容哈希。
- [x] 区分事件发生时间、首次发布时间、数据可用时间和系统抓取时间。
- [x] 历史研究只允许读取当时已经可用的数据，禁止未来数据泄漏。
- [x] 同一来源修订财报或经济数据时保留旧版本，不静默覆盖。
- [x] 为每类数据定义新鲜度、完整度、异常值和降级状态。
- [x] 数据缺失时返回机器可读原因，不用其他模块替代缺失证据。

### DATA-01 财务报表数据管线

- [x] 以现有 `packages/financial_data` 契约为基础，新增财务数据提供方接口和能力探测。
- [x] A 股接入利润表、资产负债表和现金流量表，并按保守公告时间进行点时过滤。
- [ ] A 股扩展业绩预告、业绩快报和分红送转结构化提供方。
- [x] 美股接入 10-K、10-Q、20-F、40-F 与财报发布日期，并保留 US GAAP 原始标签映射。
- [ ] 美股扩展 8-K 和公司指引结构化提供方。
- [x] 标准化季度、半年、年度、TTM 和单季度口径，禁止累计值与单季值混算。
- [x] 统一币种、单位、合并口径、会计准则和财年结束日。
- [x] 建立财务科目别名表，同时保存提供方原始字段以便审计。
- [x] 财报修订、追溯调整和来源冲突并存保存，并标记研究采用版本。
- [x] 财务与估值提供方具备重试、熔断和降级来源回退。
- [ ] 扩展后台增量抓取缓存和独立计划任务。
- [x] 生成不可变 `fundamental_snapshot` 并写入现有研究证据。

**验收标准**

- [x] 任一财务指标可追溯到报表、期间、公告时间、原始科目、来源和版本。
- [x] 在财报公告前生成的历史研究看不到该财报。
- [x] 累计季度数据能正确转换为单季度数据，缺少前序期间时明确标记不可转换。
- [x] 数据源修订后，旧研究仍恢复旧快照，新研究使用新版本。

### DATA-02 估值与可比公司数据

- [x] 定义 `ValuationSnapshot`，至少包含价格时点、股本时点、财务分母期间、币种、指标、可比组和方法版本。
- [x] 支持 PE TTM、Forward PE、PB、PS、EV/EBITDA、FCF Yield、股息率等适用指标。
- [x] 指标不适用时返回原因，例如亏损企业不展示误导性的正向 PE。
- [x] 建立行业、子行业、规模和业务相似度可比组，保存可比组版本。
- [x] 同时计算个股历史分位、行业分位和可比公司分位。
- [x] 负盈利、缺失分母和股本时点异常会失败关闭，不输出伪精确指标。
- [ ] 扩展停牌、复权、拆股、增发和跨币种换算的完整公司行为处理。
- [x] 生成不可变 `valuation_snapshot` 并写入现有研究证据。

**验收标准**

- [x] 估值分子与分母具有一致、可复核的时间口径。
- [x] 可比公司变化不会改写旧研究的历史分位结果。
- [x] 负盈利、财务缺失或股本过期时不输出虚假的精确估值结论。

### DATA-03 公司新闻与公告事件

- [x] 将新闻、交易所公告、财报披露和公司行为统一为版本化 `CompanyEvent`。
- [x] 扩展现有事件分类：财报、盈利指引、订单、并购、回购、减持、监管、诉讼、产品、管理层和资本运作。
- [x] 去重同源转载和聚合站转载，保留首发来源及转载关系。
- [x] 建立公司、人员、地区、产品、供应链、竞争对手和行业实体解析。
- [x] 保存事件重要性、方向、影响期限、受影响财务科目和可证伪条件。
- [x] 无法确认实体或来源时降级为“待核实”，不得进入高置信度建议。

### DATA-04 全球宏观事件与经济日历

- [x] 新建宏观事件域，不把宏观事件仅作为普通新闻标签处理。
- [x] 接入央行会议与决策：美联储、欧洲央行和中国人民银行。
- [x] 接入 CPI、PPI、就业、GDP、PMI、零售和利率决策。
- [ ] 扩展汇率、国债收益率和流动性指标提供方。
- [x] 保存预期值、前值、公布值、修订值、意外程度和来源。
- [x] 建立已发布和计划中状态，支持未来事件风险提示。
- [x] 形成不可变 `MacroEventSnapshot`，历史研究只消费当时已发布版本。
- [ ] 支持地缘政治、制裁、贸易政策和大宗商品冲击，但明确来源等级与不确定性。

**验收标准**

- [x] FOMC 决策能区分“预期内”和“超预期”，不只依赖标题情绪。
- [x] 经济数据修订保留初值和修订值，历史研究仍使用当时可见值。
- [x] 未来事件只作为日历风险，不能被当成已发生事实。

### DATA-05 标的关系与事件传导图

- [x] 建立公司到指数、地区、币种和利率敏感度的版本化关系底座。
- [ ] 扩展逐公司行业、商品、供应链、收入区域和监管暴露事实关系。
- [x] 关系必须区分“事实关系”“模型推断”和“用户配置”。
- [x] 每条传导边保存方向、强度、证据、有效期和方法版本。
- [x] A 股默认覆盖指数、人民币、利率和中国地区暴露。
- [x] 美股默认覆盖指数、美元、利率和美国地区暴露。
- [x] 不确定关系只进入解释层，不直接改变执行资格。

## 五、分析与统一决策

### ANL-01 财务质量与盈利趋势

- [x] 计算收入、毛利、营业利润、净利润、经营现金流和自由现金流趋势。
- [ ] 区分增长质量：价格、销量、并表、一次性项目、会计口径和汇率影响。
- [ ] 计算盈利能力、营运效率、偿债能力、资本开支、股东回报和稀释风险。
- [x] 检测利润与现金流背离和债务压力。
- [ ] 扩展应收存货异常和非经常性损益规则。
- [x] 输出 `financial_quality`、`earnings_trend`、`cash_flow_quality` 和置信度。
- [ ] 行业差异采用行业模板，不使用一套阈值评价银行、制造、软件和周期行业。

### ANL-02 估值状态与敏感度

- [x] 输出估值位置，而不是简单的“低估/高估”二元标签。
- [x] 同时展示自身历史、行业和可比公司三个参照。
- [ ] 建立盈利、利润率、贴现率和终值假设敏感度。
- [ ] 区分“低估但基本面恶化”“高估但盈利上修”“周期底部失真”等情形。
- [x] 输出 `valuation_range`、`valuation_percentile` 和失效条件。
- [ ] 补充可交互关键假设与敏感度场景。

### ANL-03 公司事件影响分析

- [x] 将事件映射到收入、现金流、资本结构、股本和风险溢价等受影响指标。
- [x] 区分短期和中期影响期限。
- [ ] 同一事件对公司、行业和竞争对手分别判断，不复用单一情绪分数。
- [ ] 计算事件新颖度、来源可信度、多源一致性和是否已被价格反映。
- [x] 输出正向、负向、中性、混合或证据不足，并保存推理证据链。

### ANL-04 宏观事件传导分析

- [x] 建立确定性传导模板：利率、汇率、通胀、需求、商品和政策风险。
- [x] 先判断事件相对预期的变化，再判断标的暴露，最后判断可能的价格与盈利影响。
- [x] 区分直接和二阶传导，避免把所有宏观新闻强行关联到每只股票。
- [x] 为每条传导输出方向、影响期限、强度、证据等级和反例。
- [x] 当标的暴露数据缺失时明确返回“无法建立可靠传导”。

### ANL-05 K 线、财报、估值与事件融合

- [x] 各模块先独立生成 `ModuleOpinion`，再进入现有 `ResearchDecision`。
- [x] 基本面改善但价格结构走弱时显示分歧，不生成“共同看多”。
- [x] 估值便宜但盈利下修时降低执行资格并解释价值陷阱风险。
- [x] 新闻冲击与财报长期趋势方向相反时保留模块分歧。
- [x] 宏观事件只在有可靠暴露关系时参与方向与置信度。
- [x] 保存模块权重、规则版本、冲突类型和未覆盖证据。

### DEC-02 场景化建议参考

- [x] 新增结构化 `ActionGuidance`，不从自然语言报告反推建议。
- [x] 建议状态使用：`继续观察 | 值得深入研究 | 等待确认 | 持有复核 | 降低风险 | 退出观察 | 数据不足`。
- [x] 根据用户是否持仓生成不同动作，不对未持仓用户显示“减仓”。
- [x] 每条建议包含主要依据、主要风险、触发条件、失效条件、复核时间和证据覆盖。
- [x] 只有统一决策可执行且数据新鲜时，才允许显示价格条件或仓位相关参考。
- [x] 方向冲突、证据不足或关键数据过期时，建议固定失败关闭为等待或补充证据。
- [x] 对非量化用户使用自然语言，对专业用户同时展示机器可读结构和计算口径。
- [x] 明确“研究参考，不是收益承诺”，但风险提示不替代具体证据说明。

**验收标准**

- [x] 相同研究数据在不同用户模式下建议状态一致。
- [x] 有持仓和无持仓用户获得不同但逻辑一致的后续动作。
- [x] 模块冲突时不会出现确定性买卖指令或虚假精确目标价。
- [x] 每个建议可回链到财报、估值、新闻、宏观和量价证据。

## 七、AI 使用边界

### AI-01 证据约束的文本分析

- [ ] LLM 只处理非结构化材料、跨证据归纳和自然语言解释。
- [ ] 财务指标、估值分位、经济数据意外值和 K 线指标使用确定性计算。
- [ ] 模型输入只包含已保存、带来源的证据摘要，并附证据 ID。
- [ ] 模型输出采用固定 schema，引用不存在的数字或事件时整项拒绝。
- [ ] 重要结论必须至少有一个直接来源；宏观传导结论必须同时有事件和标的暴露证据。
- [ ] AI 不能覆盖程序生成的证据不足、冲突或执行门禁状态。
- [ ] 支持一次受约束修复重试，仍失败则降级为结构化规则结果。

### AI-02 解释质量

- [ ] 简明模式优先回答“发生什么、为什么重要、接下来观察什么”。
- [ ] 专业模式区分事实、计算结果、模型推断和不确定性。
- [ ] 禁止使用“必涨、稳赚、确定性机会”等承诺性表达。
- [ ] 对预测性内容提供时间范围、反例和失效条件。

### QA-03 决策回归矩阵

| 场景 | 期望结果 |
| --- | --- |
| 基本面改善、估值适中、价格结构走强 | 可形成一致性偏强，但仍展示失效条件 |
| 基本面恶化、估值便宜 | 显示价值陷阱风险，不因低 PE 自动看多 |
| 财报缺失、新闻偏强 | 数据不足，新闻不能替代财务质量 |
| FOMC 超预期鹰派、标的利率暴露高 | 展示负向宏观传导和依据 |
| FOMC 事件与标的缺少可靠暴露关系 | 宏观模块不参与方向，只显示市场背景 |
| 个股新闻利好、K 线破位 | 显示短期分歧，不生成共同看多 |
| 用户已持仓且风险证据恶化 | 输出持有复核或降低风险条件 |
| 用户未持仓且证据冲突 | 输出等待确认，不显示减仓动作 |
| 财务来源修订 | 新旧研究各自保持原快照，可读差异 |
