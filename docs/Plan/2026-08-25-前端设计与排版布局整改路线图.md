# QuantHub 前端设计与排版布局整改路线图

> 审计日期：2026-08-25
> 审计视角：高频使用者日常操作路径（总览 → 研究 → 审核 → 模拟 → 复盘）
> 审计范围：`web/src` 全部 74 个 CSS 文件与 191 个 TS/TSX 文件中的样式、导航、组件层代码；`web/index.html`
> 判定原则：每一条结论都标注了源码位置；CSS 变量定义/引用差异由脚本对 `web/src` 全量扫描得出；对比度数值按 WCAG 相对亮度公式计算。凡现有文件无法确认的事项，一律列入第 6 节「需人工目检确认」，不做推断。
> 本路线图与 `docs/PRODUCT_USABILITY_AND_REPORT_REQUIREMENTS.md` 互补：该文档负责数据口径、报告可信度与多用户隔离，本文档只负责前端设计系统、排版与布局。

---

## 1. 结论摘要

前端已具备完整的令牌分层（`web/src/styles/tokens.css`：双主题颜色 → 全局字体/间距/圆角/动效 → 兼容别名）、正确的无障碍基线（skip-link、aria-current、Modal 焦点陷阱、CommandPalette combobox 语义、全局 `prefers-reduced-motion`）和统一的四态异步模式（`AsyncStateBoundary`）。主要问题集中在五处：

1. **令牌迁移未收口**：24 个被引用却从未定义的 CSS 变量散布在约 20 个文件里，直接导致背景透明、字号回退等静默渲染缺陷；同时 26 个已定义令牌零引用（含整套语义间距 `--gap-*`）。
2. **排版阶梯失控**：约 90 处硬编码 `font-size`，出现 8/9/10/16/17/24/28px 等阶梯外取值。
3. **布局约束不一致**：全部路由页根容器中只有 `FactorResearchPage` 设置了最大宽度居中，其余页面在超宽屏下拉伸到全宽。
4. **断点碎片化**：`@media` 断点出现 20 种不同数值（520px–1200px），无统一刻度。
5. **亮色主题语义文字色不达标**：`--up-ink` 在背景上的对比度为 2.93:1，低于 WCAG AA 正文要求的 4.5:1。

优先级沿用项目惯例：

- **P0**：静默渲染缺陷（未定义变量）、AA 对比度不达标——直接影响信息正确呈现。
- **P1**：排版阶梯、断点收敛、页面宽度策略、表格体系合并——影响一致性与维护成本。
- **P2**：空态/骨架屏覆盖、死令牌清理、z-index 归一——打磨项。

## 3. P1：排版阶梯与布局一致性
