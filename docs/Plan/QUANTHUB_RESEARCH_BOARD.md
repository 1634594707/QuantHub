## 1. 状态机（唯一允许的状态）

```
backlog → ready → in_progress → review → canary → production → verified
                                                  ↑              ↓
                                                  └── rollback ──┘
或：blocked / cancelled
```

| 状态 | 含义 | 进入条件 |
| --- | --- | --- |
| `backlog` | 已登记，未排期 | P0-03 立项时写入 |
| `ready` | 依赖已清、可开工 | 前置工作包 `verified` 或 `production` |
| `in_progress` | 正在实现 | 认领后 |
| `review` | 实现完成待审 | PR 提交 / 自测通过 |
| `canary` | 灰度环境已部署 | M3-02 门禁通过 |
| `production` | 生产已发布 | 人工确认发布 |
| `verified` | 生产运行 + 验收证据齐 | 试点指标达标 |
| `blocked` | 被依赖 / 外部阻塞 | 标注阻塞源 + 解除日期 |
| `cancelled` | 明确取消 | 决议取消，保留记录不可删 |
