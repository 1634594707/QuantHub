# QuantHub v0.3.0 AI 因子研究治理发布说明

更新日期：2026-08-01

本版本把 AI 用于提出结构化经济假设、DSL 公式和证伪建议；统计结论、生命周期状态与交易门禁仍由确定性程序产生。LLM 不读取锁定确认集标签，不执行任意 Python，也不直接产生买卖指令。

## 状态口径

- `research_passed`：仅表示因子通过锁定样本外统计门禁，不代表可交易，更不代表实盘收益。
- `trading_validated`：必须额外通过至少一个完整模拟再平衡周期、成本后表现、成交率、容量、执行约束和组合增量价值门禁。
- `degraded` / `retired`：漂移或交易门禁失效后的降级和退役状态，历史定义与证据继续保留。
- 实盘可用：本版本没有该状态；真实账户自动交易保持关闭。

## 新增治理能力

- 候选收件箱区分人工、AI、模板、随机 DSL 和符号回归来源，并分别展示探索分数、研究状态、交易状态与 AI 审阅。
- 未通过因果、数据或未来信息检查，或未获研究人员预算批准的候选，不提供开始回测入口。
- 非线性模型只作为嵌套时间序列对照；只有稳定优于线性 Ridge 基准才可进入模拟。
- A 股、美股、加密资产和 MT5 使用独立组合约束，包括单标的权重、行业偏离、成交额参与率和换手预算。
- 漂移监控覆盖 IC 衰减、方向翻转、覆盖下降、PSI、分布距离、相关结构、成本和容量，并返回受影响策略列表。
- 研究期与模拟期差异拆分为信号衰减、数据延迟、成交、成本和组合约束，保留未解释残差。

## 证据边界

已完成 300 个真实 A 股标的、516 个共同 ordinal session 的只读横截面基线，以及 6 个预注册实验。结果为 1 个实验通过、5 个失败；通过统计门禁仍不代表交易可用。当前数据没有真实自然日期、历史退市/ST/指数成分变化和时点行业、市值、Beta 暴露，因此这些证据仍明确缺失，禁止用当前静态值回填。

模拟订单现保存因子/研究运行、再平衡周期、信号时间、可成交时间、理论价、模拟成交价、方向一致滑点、拒单原因与容量占用。持续监控门禁失败会在一个调度周期内追加 `degraded` 事件并定位受影响策略；重复调度保持幂等。以上均限定为影子或模拟环境，`live_trading_enabled=false`。
