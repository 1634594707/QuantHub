# QuantHub v0.1.1

`v0.1.1` 聚焦研究工作流、因子验证和首次使用体验。综合评估、确定性量化计算、受约束的 AI 复核与结果导航现在形成一条可追溯链路。

## 主要更新

### 综合评估工作台

- 工作台顶部新增“一键评估”，无需返回起始页即可启动现有综合评估任务。
- 评估过程展示准备数据、量化快照、新闻 AI、价格结构 AI、模型共识和报告生成六步状态。
- 运行中禁止重复启动，失败时显示原因、影响与处理建议。
- A 股运行完整模块；美股与加密资产自动跳过当前不可用的独立新闻模块。
- 桌面和移动端使用同一入口，移动端无页面级横向溢出。

### 因子研究与回撤验证

- 14 个趋势、反转、突破、量价和风险因子统一经过训练隔离与样本外验证。
- 增加 Rank IC、Pearson IC、ICIR、IC 衰减、方向命中率、相关性去重与近似显著性信息。
- 同口径比较买入持有、趋势跟随、动量、均值回归、通道突破和多因子组合。
- 增加最大回撤、当前回撤、Ulcer Index、VaR、CVaR、Calmar、下行偏差和恢复状态。
- 输出正常、观察、减仓、风险退出和修复五级风险动作；这些动作只用于研究与人工审核。

### 保存、恢复与 AI 科研复核

- 因子研究完成后自动保存参数、数据来源、结果与稳定 `run_id`，支持刷新恢复、历史查看和同标的对比。
- AI 复核读取锁定的结构化研究快照，检查过拟合、样本量、IC 衰减、成本敏感度和市场状态依赖。
- AI 输出经过结构、枚举、因子键和数量校验，只能提出风险与可证伪实验，不能修改量化状态。
- 基础因子计算与回撤验证无需 API Key；只有用户显式启动 AI 功能时才会调用所配置的模型供应商。

### 新手易用性与结果回链

- 新增短线、波段、中线周期模板，以及稳健验证、趋势研究和回撤检查研究目的模板。
- 新增正常、风险退出、数据不足和 AI 失败四类示例报告。
- 新增 IC、ICIR、样本外、CVaR、Calmar 和回撤信号的按需中文解释。
- 结果摘要先回答结论、依据、风险、失效条件和下一步，专业统计保持可展开。
- 研究任务、自动化、提醒、信号、故障与全局检索统一回链到研究正文；自动化只保存结果类型与 ID，不复制正文。
- 本机匿名易用性指标只记录步骤、耗时、放弃和错误分类，不采集标的、密钥、持仓或模型配置。

## 升级

```bash
git fetch --tags
git checkout v0.1.1
uv sync --locked
npm --prefix web ci
```

Windows 可继续使用统一启动脚本：

```powershell
powershell -ExecutionPolicy Bypass -File tools/start-quanthub.ps1
```

容器镜像：

```bash
docker pull ghcr.io/1634594707/quanthub:v0.1.1
```

## 安全边界

- 实盘交易默认关闭，发布内容不改变 `live_trading=false` 的安全默认值。
- 一键评估只创建研究任务，不创建实盘订单。
- 回测、因子筛选与 AI 输出均不构成投资建议，也不代表未来收益。
