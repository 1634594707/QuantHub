# QuantHub v0.4.0

`v0.4.0` 将 QuantHub 的研究、验证和模拟执行流程收口到一个本地优先的 Web 工作台，并把 Factor Factory 从候选生成推进到可重复实验、确定性筛选、锁定确认和 7 天真实时间模拟门禁。

## 主要更新

### 单一 Web 工作台

- 唯一用户入口为 `http://127.0.0.1:5173`，统一承载总览、研究、策略、交易、风控和设置。
- 提供精简与完整两种界面范围；修复设置页悬浮导航遮挡和研究页上下文混乱问题。
- 移除首次访问自动写入的演示持仓、自选种子和静默 mock 回退，真实数据失败会明确展示原因。

### Factor Factory 可执行研究链路

- 每次实验绑定 `market + symbol + interval`，候选、详情和下一轮选择只属于当前研究标的；通过 `experiment_nonce` 支持同一标的重复实验。
- 支持 BRAIN 风格规则挖掘、人工 JSON、固定候选库和 AI 提案，并可选择已配置的 DeepSeek 或兼容 API。
- 候选检查器展示完整 DSL、因子家族、来源、阶段、实际/请求样本覆盖、门禁结果、淘汰原因和真实前向净值曲线。
- 安全 DSL 先进行 AST、未来数据和参数边界检查，再按公式哈希去重，并按实际信号相关性过滤冗余候选；跨家族高相关阈值为 `0.985`。
- 统一执行滚动样本外验证、回撤与交易次数门禁及双倍成本压力测试，只有排名最高且全部通过的一个候选进入锁定确认集。
- 优胜因子进入 OKX Demo 或本地模拟后，必须累计至少 7 个真实自然日，并通过收益、夏普、成交率、容量、风险和对账门禁。

### OKX 数据与本地凭据

- 接入 OKX 公共合约目录和实时公共 K 线；历史请求不足时，只要仍有至少 `240` 根有效 K 线即可继续研究并展示实际覆盖。
- 行情不足或不可用返回可解释的 `422`，避免把数据问题表现为笼统的服务器 `500`。
- Windows 本地凭据使用当前用户的 DPAPI 加密保存在仓库之外；设置页支持保存、替换、只读测试和确认删除。
- OKX Demo 只读凭据验证已成功。Runner 继续以 `shadow` 为默认安全环境，Demo 失败不会回退到实盘。

## 当前边界

- Factor Factory 的人工和 AI DSL 当前面向单标的 OHLCV 时序数据。财务字段、情绪字段、`subindustry` 分组排名和大规模横截面计算仍需要稳定的截面数据层。
- 7 天模拟是单个优胜候选的最终通过/失败门禁，不是多个候选并行竞赛，也不构成实盘授权。
- 实盘交易默认关闭；启用真实执行仍需独立配置、人工批准、完整风控和更长观察期。
