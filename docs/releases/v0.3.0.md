# QuantHub v0.3.0

`v0.3.0` 将 QuantHub 的固定技术因子筛选流程升级为可扩展、可审计的 AI 辅助因子发现系统。AI 负责生成结构化假设和审阅证据，确定性程序继续独占数据验证、统计结论、生命周期状态和模拟交易门禁。

## 主要更新

### 因子注册表、安全 DSL 与研究治理

- 新增不可变 `FactorDefinition` 注册表，保存公式 AST、参数、方向、持有期、可用延迟、经济逻辑、版本与哈希。
- DSL 使用白名单算子并检查因果方向、单位、形状、复杂度、数据覆盖和重复公式，阻止未来函数进入计算队列。
- 新增全局 `FactorExperiment` 账本、研究预算、不可逆确认集开启记录、累计多重检验和失败原因反馈。
- AlphaGPT 与 AlphaMaster token 公式通过适配层进入统一注册表，不再保留不可审计的独立公式路径。

### AI 辅助发现与证据工作台

- AI 提案采用结构化 schema，包含经济假设、目标市场、数据字段、可用延迟、DSL AST、失效条件和证伪实验。
- 候选收件箱区分人工、AI、模板、随机 DSL 和符号回归，并要求研究人员批准候选与预算后才能进入搜索。
- AI 不能读取锁定确认集标签，不能修改 `research_passed` 或 `trading_validated`，也不能直接产生交易指令。
- 因子证据工作台分开展示探索、研究、交易和 AI 状态，并回链 DSL、数据验证、实验、统计、组合和模拟证据。

### 真实研究证据

- `demo_artifacts/a_share_300_factor_baseline.json` 保存 300 个真实 A 股标的、516 个共同 ordinal session 和 14 个因子的只读基线。
- `demo_artifacts/a_share_preregistered_experiments_01_07.json` 保存实验 1、2、3、4、5、7 的完整候选结果；6 个实验中 1 个通过、5 个失败。
- 最新 `600519` 研究在没有可用因子时明确返回 `multifactor_constructed=false`，不会把拒绝因子混入组合。
- 数据、公式、实验、模型、提示词、成本和结果分别保存版本与哈希，失败证据与成功证据同等保留。

### 模拟交易审计与持续监控

- 模拟订单保存研究因子、因子版本、研究运行、再平衡周期、信号时间、可成交时间、理论价格和容量占用。
- 每笔模拟成交保存模拟价格、方向一致滑点、拒单原因和账本同步状态，可直接作为模拟交易门禁证据。
- 漂移监控覆盖 IC 衰减、方向翻转、覆盖率、PSI、分布距离、相关结构、成本和容量。
- 监控失败会在同一调度周期追加 `degraded` 生命周期事件、保存阈值与指标并定位受影响策略；重复执行保持幂等。

## 兼容与安全边界

- 历史研究结果继续保留，非当前引擎记录明确标记为旧引擎只读口径，不自动重算或覆盖。
- 数据库升级到 revision `0009`；模拟审计和因子治理证据只追加，不在降级时删除。
- 真实研究数据目前使用 ordinal session，不能声明为真实自然日期。
- 历史退市/ST/指数成员、时点行业/市值/Beta 暴露和人工新闻标注仍缺少完整真实证据，禁止使用当前静态值回填。
- 统计通过不等于交易可用；没有完成模拟成本、成交率、容量和完整再平衡周期门禁的因子不得升级为 `trading_validated`。
- 实盘交易继续默认关闭。所有新增订单和生命周期能力仅用于研究、影子组合和模拟执行。
