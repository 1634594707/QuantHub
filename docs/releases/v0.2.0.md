# QuantHub v0.2.0

`v0.2.0` 把单标的因子筛选扩展为可复现、可审计、可持续复验的多市场研究流程。统计状态、交易成本、数据快照、调度运行、提醒和策略实验使用明确契约连接，不以 AI 输出替代统计检验。

## 主要更新

### 多窗口、跨标的与跨市场验证

- 因子研究支持扩展窗口和滚动窗口 walk-forward，保存每个训练、隔离和验证区间。
- 统计结果新增窗口通过率、最差窗口 IC、IC 中位数、IC 四分位距、方向翻转和状态迁移。
- 横截面研究使用带生效日期的历史股票池，纳入退市、停牌、ST 和上市时间，输出每日 Rank IC、ICIR、分层收益、多空收益、覆盖率、缺失率、换手、容量和拥挤度。
- 行业、市值和 Beta 中性化失败会保留为原始证据；A 股、美股、加密资产和 MT5 均需通过最新横截面门禁才能进入“交易验证通过”。

### 可审计成本和容量受限执行

- 成本档案保存数值、单位、标准化 bp、来源地址、抓取时间、生效区间、市场、标的和账户范围。
- A 股执行约束覆盖佣金、印花税、过户费、涨跌停、停牌和整手；美股覆盖点差、佣金和公司行为确认。
- 加密资产覆盖账户费率等级、资金费率、点差和滑点；MT5 覆盖点差、隔夜利息、合约乘数和滑点。
- 成交量乘以参与率形成每根 bar 的最大成交容量。档案缺项时执行模拟直接拒绝运行，不填充未知券商费率、OKX 账户费率或 MT5 合约参数。
- 成本和执行约束同步影响成交明细、权益曲线、成交率、总成本和交易收益。

成本来源及录入边界见 [交易成本来源与录入边界](../TRADING_COST_SOURCES.md)。

### 研究生命周期和高频操作

- 策略实验锁定研究运行 ID、因子定义、权重、周期、成本配置和行情快照，执行阶段不再重新取数。
- 因子历史支持市场、周期、状态、日期和参数筛选，并支持收藏、备注、标签、批量归档、任意两次运行对比和 JSON/CSV/可读报告导出。
- 新增窗口、跨标的和跨市场统一状态矩阵；状态行可展开查看计算规则、原始证据和研究运行 ID。
- 首页行动队列显示需要复验、已失效和数据过期研究，并直接回链到对应记录。

### 定时复验、提醒和故障治理

- 因子股票池作业支持日、周、月 Cron 调度、失败重试和断点恢复。
- 因子状态变化、IC 衰减、回撤越界和数据过期使用专用提醒规则；调度完成后在同一周期检查规则并保存回链事件。
- 故障中心聚合数据源错误、统计验证失败和研究持久化错误。
- 同一可选依赖错误在单个进程生命周期内只产生一次可见告警，后续同类错误聚合为调试记录。
- API 健康检查返回运行版本、启动源码标识、当前源码标识和是否需要重启。

### 行情准确性

- Yahoo 使用 `adjclose` 比例同步调整 OHLC，并在公司行为附近执行复权连续性检查。
- 修正 Yahoo 在逆序或重复行情清理前执行连续性检查导致的误报。
- Akshare、东方财富、腾讯、Yahoo 和 OKX 统一清理缺失 OHLC、重复时间与逆序数据，并输出明确公司行为处理元数据。

## 兼容与安全边界

- 现有未提供成本档案的因子请求继续使用明确传入的 `transaction_cost_bps`；只有进入市场执行模拟时才要求完整档案。
- 历史研究记录缺少新字段时仍可读取，界面显示“旧记录未保存”。
- 实盘交易继续默认关闭；本版只增强研究、策略实验和模拟执行，不会绕过信号审核或人工确认。
- 所有研究结果、回测结果和 AI 输出均不构成投资建议，也不代表未来收益。

### Schema revision 与回滚

- 本版数据库 revision 为 `0003`，采用因子股票池、因子复验作业、研究故障，以及研究标签、归档和策略实验回链结构。
- 升级前先停止 API、调度器和 dispatcher，并按 [升级与扩展](../UPGRADE.md) 创建、校验数据库备份，再执行 `uv run alembic upgrade head`。
- 回滚时停止所有写入进程，切回 `v0.1.1`，同步该版本依赖，然后使用 `uv run python -m tools.backup_store restore <已校验的升级前备份> --yes` 恢复数据库。
- 不手工降低 schema revision，也不在原数据库上删除新表或字段；这些操作会丢失研究历史、标签、作业和故障记录。

### 已知限制

- 四市场交易验证要求分别提供对应市场的最新横截面研究证据，不会用单标的结果替代。
- 市场执行模拟在成本档案或公司行为确认缺失时拒绝运行，需要用户补录可追溯来源。
- 全仓 Ruff 历史基线仍有 109 项存量问题；本版新增和修改的 Python 文件通过 Ruff 检查。
