## 关键设计决策
- 默认暗色：契合长时间盯盘 + 你 DispatchFlow 暗色偏好；涨绿跌红跨主题恒定，避免误读。
- 数字一律等宽 + tabular-nums，列对齐、跳动不抖。
- 设计 Token 直接对应 CSS 变量，React/Vue 可 1:1 迁移为 theme 扩展。
