# QuantHub 策略模块 · 板块功能与前端页面设计

> 范围：把"策略模块"视为覆盖**策略全生命周期**的子平台——发现 → 统筹 → 验证 → 消费 → 部署。
> 设计原则（沿用用户既定要求）：每个板块**细节化、功能可用、数据尽量接真实源**；沿用 `tokens.css` 双主题 + `StrategyShared` 共享组件；诚实数据（无源不伪装）。

---

## 0. 信息架构（IA）

```
策略库(发现) → 策略工作台(统筹/运行) → 回测工作台(验证) → 信号中心(消费) → 组合管理(部署,规划)
                                      ↘ PA 分析工作台(并行专属深度页)
```

| 阶段 | 板块 | 路由 | 状态 |
|---|---|---|---|
| 发现 | 策略库 | `/strategies` | ✅ 已建（搜索/筛选/快速运行） |
| 统筹 | 策略工作台 | `/strategies/:name` | ✅ 已建（参数/预设/历史/信号） |
| 验证 | 回测工作台 | `/backtest` | ⚠️ 极简（仅运行+信号表） |
| 消费 | 信号中心 | `/signals` | ⚠️ 平铺表（缺筛选/聚合） |
| 部署 | 组合管理 | （规划） | 🔲 Task #68 第二部分 |
| 专属 | PA 分析工作台 | `/pa` | ✅ 已建（共享视图层） |

## 1. 板块一 · 策略库（Strategy Library）`/strategies`

**定位**：策略的入口与总览——发现、筛选、快速试跑。

**功能**
- 已实现：搜索（名称/描述）、市场筛选、仅可实盘、排序（默认/名称/最近运行）、按市场分组 + 数量徽标、卡片展示最近运行状态（本地运行历史）、快速运行按钮。
- 待补：
  - **策略类型**维度（选股 / 择时 / 网格 / 情绪 / PA），与"市场"双轴筛选；
  - **网格 / 列表视图**切换；
  - **多选对比抽屉**（并排看参数 schema 与最近表现）；
  - **组合扫描**（一键对全市场/选股池跑某策略，结果汇入信号中心）。

**页面设计**
```
[card-head] 策略模块 · 已注册 N 个            [刷新]
[strategy-toolbar] [搜索框] [全部|A股|加密|美股|其他 计数] [仅可实盘] [排序▼]
[分组 section]  市场标题 + 数量
  [strategy-grid]  ┌策略卡┐ ┌策略卡┐ ┌策略卡┐  (auto-fill 响应式)
                  名称+市场badge+可实盘badge / 描述
                  状态行 + [快速运行(磁吸)] [详情→]
```

**交互**：点击卡片进详情；快速运行带 loading 与乐观状态；骨架加载；空态提示。
**数据**：`GET /strategies`（真实注册）+ 本地运行历史（`localStorage`）。
**差距**：缺"类型"维度、无对比、无组合级扫描。

## 2. 板块二 · 策略工作台（Strategy Workspace）`/strategies/:name`

**定位**：单策略的"驾驶舱"——理解、配置、运行、复盘。

**功能**
- 已实现：策略说明、参数预设（保存/加载/删除，localStorage）、运行历史（恢复结果与参数）、参数编辑器、`run`、信号结果（方向筛选 + 排序 + 列表）。
- 待补：
  - **Tab 化布局**：概览 / 参数 / 运行 / 历史 / 信号；
  - **信号可视化**：方向环图（做多/做空/观望）、分数分布直方图、平均置信度；
  - **收藏到信号中心**（跨策略聚合）；
  - 与回测结果**联动对比**（同参数历史 vs 当前）；
  - 定时/自动运行（需后端）。

**页面设计**
```
[card-head] ← 名称 + 市场badge + 可实盘badge
[tab-bar]   概览 | 参数 | 运行 | 历史 | 信号
[概览]  说明 + 关键指标卡(最近信号数/成功率/平均分) + 迷你方向环图
[参数]  ParamsEditor(可视化字段 + JSON 兜底) + 预设管理条(保存/加载/删除)
[运行]  参数 + [运行CTA(磁吸)] + 结果区(SignalStats + 方向筛选 + 排序 + SignalRow 列表)
[历史]  时间线式记录，可"恢复结果与参数"
[信号]  独立筛选/排序/导出
```

**交互**：tab 切换淡入（尊重 `prefers-reduced-motion`）；运行 loading；恢复历史回填参数+结果；信号行 hover 高亮。
**数据**：`GET /strategies/{name}` + `POST /strategies/{name}/run` + 本地预设/历史。
**差距**：当前单页纵向堆叠，信息密度高但可分层；缺可视化图表。

## 3. 板块三 · 信号中心（Signal Center）`/signals`  ← 重点细节化（Task #68）

**定位**：跨策略的"情报流"，所有信号的统一消费层。

**功能**
- 已实现：平铺表格（标的 / 方向 / 得分 / 置信度 / 周期 / 来源 / 标签 / 时间）+ 刷新。
- 待补（优先做）：
  - **多维筛选**：来源策略、方向、市场、分数阈值（滑块）、时间范围、标签、关键词；
  - **聚合概览**：总信号数、平均分数、平均置信度、方向分布环图、按策略热力；
  - **分组视图**：按策略聚合的概要卡（每策略 多/空/观望 + 平均分）+ 其下 Top 信号；
  - **行交互**：点击展开 reason/meta、标记已审阅、加入关注/组合；
  - **保存视图 + 导出 CSV**；分数随时间 sparkline。

**页面设计**
```
[card-head] 信号列表 · 实时/模拟 · 共 N 条        [刷新]
[概览条]   方向分布(做多/做空/观望) + 平均分 + 平均置信度   (复用 SignalStats 风格)
[筛选栏]   [来源策略▼] [方向] [市场] [分数≥] [时间] [搜索]
[视图切换] 表格视图 | 分组视图
  表格: 现有表格增强(可排序列 + 行展开)
  分组: 每策略一张概要卡 + 其下 Top 信号(复用 SignalRow)
```

**交互**：筛选即时（受控）；分组/表格切换；行展开抽屉显示完整 meta/tags/reason；导出。
**数据**：`GET /signals`（真实，限时 100）→ 建议后端支持 filter / 分页 / 按策略聚合（否则前端本地过滤）。
**差距**：当前只是 raw 表，缺筛选/聚合/概览，未与策略页联动。

## 4. 板块四 · 回测工作台（Backtest Workbench）`/backtest`

**定位**：历史验证，量化策略表现。

**功能**
- 已实现：策略网格 + 运行 + 结果表（标的/方向/得分/置信度/周期）—— 仅"再跑一次出信号表"。
- 待补（需后端支持或前端简化并诚实标注）：
  - 参数输入（复用 `ParamsEditor`）；
  - **时间区间**选择（起止日期）；
  - **绩效指标**：胜率、盈亏比、夏普、最大回撤、收益曲线（equity curve）；
  - 多次运行**对比**（同策略不同参数）；
  - 与策略工作台"运行"语义区分：**回测=历史**，**运行=当前信号**。

**页面设计**
```
[左栏] 策略选择 + ParamsEditor + 时间区间 + [运行回测CTA]
[右栏] 结果区
  绩效卡(指标网格: 胜率/盈亏比/夏普/回撤)
  收益曲线(轻量 SVG/Chart)
  信号明细表(复用 SignalRow)
```

**数据**：`POST /strategies/{name}/run` 返回 signals；绩效需在后端新增 metrics，或前端基于 signals 做**简化处理并诚实标注"简化指标"**。
**差距**：最大——当前几乎无"回测"语义。

## 5. 板块五 · 组合管理（Portfolio / Deployment）— 规划中（Task #68 第二部分）

**定位**：把策略部署为实盘/模拟组合，监控持仓与风险。

**功能（规划）**：绑定策略→组合、纸面/实盘开关（仅可实盘策略）、持仓监控（复用 `HoldingsTable`）、未实现盈亏、风险指标（敞口/集中度）、执行日志；与持仓明细/关注列表（localStorage 可编辑）打通。
**页面设计**：组合列表 + 组合详情（策略绑定 / 持仓 / 绩效 / 日志）。
**数据**：`/portfolio`（已有成本/市值）+ 实盘执行需券商/交易所对接（当前无源 → 诚实标注）。

## 6. 板块六 · PA 分析工作台（PA Workbench）`/pa` — 专属深度页

**定位**：`pa_agent` 两阶段分析的 Web 孪生（已抽共享视图层）。
**现状**：已有丰富 view-model 渲染（决策面板 / 关键位 / 形态）。
**一致性**：沿用同款卡片/状态样式，确保与策略模块视觉同源；非通用策略，保持独立但风格统一。

## 7. 跨板块一致性（设计系统）

- **统一板块头**：`card-head`（标题 + sub + 动作）。
- **统一策略卡**：`StrategyCard`（库 / 回测 / 侧边栏复用）。
- **统一信号呈现**：`SignalRow` + `SignalStats` + `directionColor`（详情 / 回测 / 信号中心复用）。
- **统一参数**：`ParamsEditor` + `paramFields`（详情 / 回测复用）。
- **统一状态语义**：运行态 / 成功 / 失败 / 可实盘 / 市场 badge。
- **主题与质感**：`ThemeProvider` 暗亮双主题；玻璃表面（`--bg-elevated` + border + `shadow-card`）；磁吸 CTA；骨架加载；focus ring；`prefers-reduced-motion`；响应式（网格塌缩为单列、工具栏换行）。
